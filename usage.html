数据怎么来的

  • ChatGPT：每天自动从 OpenAI 账号读取官方的累计和每日 Token 数，包括 ChatGPT Work 模式与 Codex（不包括 Chat 模式）运行的任务和其他设备上的使用。
  • Claude：读取 Claude Code 本地会话记录。每条回复都记了云端 Token 数。
  • Grok：Grok 没有本地记录，数字来自 xAI 控制台导出的用量明细。
