数据怎么来的

  • Codex 累计：来自 Codex 应用，按整个账号统计，包括在云端运行的任务和其他设备上的使用。这个数字是我手动更新的。
  • 图表里的 Codex 只算这台电脑上的对话，而且较早对话的记录不完整，所以比上面的累计数少。
  • Claude Code 和 Cowork：读取 Claude 应用在这台电脑上保存的会话记录。每条回复都记了 token 数，这里算的是输入、输出和缓存读写的总和。
  • Codex：读取 Codex 在本地保存的逐次记录，算的是输入（含缓存）和输出的总和。较早的对话没有逐次记录，只有每个对话的总数，按它在各天的使用时长分摊到每天，这些日子标为估算。
  • token 里大部分是每轮对话都要重新带上的上下文，所以不等于写出了多少字。
  • 不包括网页版和手机 App 里的聊天，也不包括 Grok：这些用量没有留在本地。
  • 已经记下的数字不会因为删掉旧会话而减少。
